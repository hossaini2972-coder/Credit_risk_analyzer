# Credit Risk Modeling Project

## Problem Statement
This project predicts whether a customer is likely to default on a loan based on financial and behavioral data.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Model Training
- Risk Prediction
- Streamlit Frontend
- Report Generation

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Model Used
- Logistic Regression
- Random Forest Classifier
